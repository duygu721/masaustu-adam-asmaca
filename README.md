# 🎮 Masaüstü Adam Asmaca

Java Swing kullanılarak geliştirilmiş masaüstü Adam Asmaca oyunudur.

Oyuncu, rastgele seçilen kelimeyi harf tahmin ederek veya kelimenin tamamını tahmin ederek bulmaya çalışır.

## ✨ Özellikler

* 🔤 Harf tahmini yapma
* 💭 Kelimenin tamamını tahmin etme
* ⏱️ Oyun süresini takip etme
* 🎲 Rastgele kelime seçimi
* 🔐 Şifreli giriş sistemi
* 📊 Skorları görüntüleme
* 📝 Log kayıtları
* 🖼️ Yanlış tahminlere göre adam asmaca görsellerinin değişmesi
* 💾 Oyun bilgilerinin dosyalarda saklanması

## 🛠️ Kullanılan Teknolojiler

* Java
* Java Swing
* File I/O
* JTable
* Timer
